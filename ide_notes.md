# Работа с Git: VS Code и Терминал

## удобные вещи в VS Code

- **Цветные маркеры на полях:** сразу видно, какие строки добавлены, изменены или удалены.
- **Кнопки в один клик:** Commit, Push и Pull делаются мышкой, без ввода команд.
- **Наглядный Diff:** клик по файлу в панели Git открывает удобное сравнение старой и новой версии кода.

## удобнее в терминале

- **Быстрая проверка статуса:** команды `git status` или `git log` выполняются мгновенно и дают всю нужную информацию без открытия графических панелей.
