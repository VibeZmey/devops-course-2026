# Цели на семестр

1. **Освоить Git и GitHub на практике.** Научиться уверенно работать с ветками, делать Pull Request'ы и решать merge-конфликты.
2. **Создать и опубликовать пет-проект.** Написать одно законченное приложение, оформить для него понятный README и выложить на GitHub.
3. **Повысить качество кода.** Научиться писать базовые тесты и использовать линтеры, чтобы код был не только рабочим, но и чистым.
